Help, Onboarding & Safeguard Guide

  1. Create a Client: Go to Clients → + Add Client, enter website domain, Google Sheet URL, and add client locations.
  2. Import Keywords Safely: Open Google Sheets, connect Google OAuth (docs/GOOGLE_CLOUD_SETUP.md), preview sheet groups/rows, and confirm import.
  3. Run Verified Ranking Checks: Open Jobs & Checks, verify GPS & Google Search location on the visible tab, and start bulk ranking.
  4. Review History & Update Sheets: Inspect movements in Keyword Rankings / Ranking History, create a mandatory recoverable backup, verify the Dry-Run Preview, and confirm spreadsheet update in Google Sheets.
